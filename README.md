# Weather App

Веб-додаток для перегляду поточної погоди в будь-якому місті.

## Можливості

- Пошук погоди за назвою міста (українською або англійською)
- Поточна температура, стан погоди, вологість і швидкість вітру
- Оформлення сторінки змінюється залежно від погоди: ясно, хмарно, дощ, сніг, гроза
- Кеш результатів на 10 хвилин: повторний пошук того самого міста не робить запитів до API

## Технології

- Angular 21 (standalone-компоненти, signals)
- RxJS
- Vitest для unit-тестів

## Запуск

```bash
npm install
npm start
```

Додаток буде доступний за адресою `http://localhost:4200/`.

## Тести

```bash
npm test
```
